Examples

Every example is a runnable document in lang/examples. Run them from the lang folder, for example spl examples/hi.md: relative paths and imports resolve against the working directory. Each example's header shows its arguments.

Getting started#

Example Shows
hi.md A struct schema with one repair, a blockquote saving a shared variable, the Markdown builder

Extract an invoice#

The struct schema checks the shape of the answer; a reusable Money alias documents that amounts are integer cents. Annotations such as minimum: 0 are advice for the model, not constraints; plain arithmetic checks that the numbers add up.

Triage issues#

Exact gh calls fetch and label issues; the model only classifies, and nothing changes until a person approves.

Plain JavaScript#

No model is involved here: the workflow imports Node.js built-ins, declares a function and ends with a JSON result.
