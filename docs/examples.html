Examples

Every example is a runnable document in lang/examples. Run them from the lang folder, for example spl examples/hi.md. Each example's header shows its arguments.

Getting started#

Example Shows
hi.md Code and natural language sharing variables, a schema, an assertion and a restricted write
basics.md Checking a model's answer against exact code; guidance with @ENFORCE and @FORBID
is-friday.md Branching on a JSON answer
env.md Reading $env and --arg values
color-poem.md Asking a person with @HUMAN (needs --checkpoint)

Developer workflows#

Example Shows
code-review.md A review that fails CI on high-severity findings
release-notes.md User-facing notes from git log prepended to CHANGELOG.md
triage-issues.md Labeling GitHub issues with gh after human approval

Data and documents#

Example Shows
extract-invoice.md Structured extraction checked by arithmetic
translate-docs.md Translations verified to keep links, code and headings
incident-report.md Exact log statistics, model-written narrative
web-digest.md Web research with restricted fetches and checked citations

Agents, state and people#

Example Shows
mcp.md An agent limited to one MCP tool
journal.md State across runs with --store
human-review.md Pausing for review with --checkpoint and resuming with the answer

Extract an invoice#

The schema checks the shape of the answer; plain arithmetic checks that the numbers add up.

Triage issues#

Exact gh calls fetch and label issues; the model only classifies, and nothing changes until a person approves.
