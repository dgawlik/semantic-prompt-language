The language

Language basics

The deterministic half of SPL: a Python-flavoured language with braces. Nothing on this page calls a model — given the same inputs it always produces the same results.

📌
Design decisions at a glance
  • Blocks use braces; the opening { must be on the same line as its keyword. Statements end at a newline (or ;).
  • let binds in the enclosing function scope, not per block. x = … reassigns an existing variable.
  • Every string interpolates {expr}.
  • Strict parsing: unknown modifiers or values, break outside loops, return outside functions, and try without except are syntax errors (exit code 2).

Program structure

A script is an optional @{…} directive header followed by statements. # starts a comment that runs to the end of the line.


@{model='gpt-5'}        # header: only allowed before the first statement

let greeting = 'hello'  # a statement
log(greeting)           # an expression statement

Directives

The only directive in the MVP is model. Its value must be a plain string (no interpolation). The --model CLI option takes precedence over the directive.

Variables

Declare with let; variables are mutable for the duration of the run. Reassign with = or a compound operator (+= -= *= /= //= %=). Assigning to an undeclared name is a runtime error.


let count = 0
count += 1                 # ok
total = 5                  # runtime_error: cannot assign to undeclared variable 'total'

let user = {'name': 'Ada'}
user.name = 'Grace'        # member assignment
user['age'] = 36           # item assignment

Scope

let inside if, for, while, try and restrict blocks is visible after the block — scope is per function. Functions are closures; parameters are local to the call.


try {
    let response = ?{fmt='object'} 'A joke about programmers'
} except err {
    let response = {'setup': 'none', 'punchline': err.reason}
}
log(response)              # visible here, whichever branch ran

Persistence

Top-level variables can be saved between runs with the variable store (--store). See CLI & runtime.

⚠️

Compare it with a quoted name: type(x) == 'list'. There is no separate int/float distinction — both report 'number'.

Truthiness

None, False, 0, empty strings, empty lists and empty dicts are falsy. Everything else (including functions) is truthy.

Strings & interpolation

All four quote styles interpolate {expression}. Any expression is allowed, including calls and indexing. Substitution is as is: strings raw, True/False/None in Python spelling, lists and dicts as JSON.


let items = ['a', 'b']
let n = 2
log("found {n} items: {items}")          # found 2 items: ["a","b"]
log("first is {items[0].upper()}")       # first is A
log("{{literal}} and \{also literal\}")  # {literal} and {also literal}
log(r'{"raw": "no {interpolation} here"}')

Quote styles & escapes

FormBehaviour
'…'  "…"Single line; escapes and interpolation.
'''…'''  """…"""May span lines; escapes and interpolation. Ideal for prompts.
r'…'Raw: no escapes, no interpolation.

Valid escapes: \n \t \r \0 \\ \' \" \{ \}. Anything else is a syntax error, and so is a stray single } in a string — write }} or \}.

let xs = [10, 20, 30, 40]
log(xs[-1])                  # 40
log(xs[1:3])                 # [20,30]
log('ab' * 3)                # ababab
log('x' in 'text')           # True
log('role' in {'role': 1})   # True  (dicts test keys)
log(7 // 2, 7 % 3, 2 ** 10)  # 3 1 1024
let label = 'many' if len(xs) > 3 else 'few'

Control flow

if / elif / else


if score >= 90 {
    grade = 'A'
} elif score >= 80 {
    grade = 'B'
} else {
    grade = 'C'
}

for & while

for iterates lists, strings (characters) and dicts (keys). Several names unpack list items, which pairs well with items() and enumerate(). break, continue and pass work as in Python.


for i in range(3) { log(i) }

for code, language in items({'de': 'German', 'pl': 'Polish'}) {
    log("{code} = {language}")
}

let tries = 0
while tries < 3 {
    tries += 1
    if tries == 2 { continue }
}

Functions

Define with def. Functions take positional arguments only (the count is checked), return None unless return is used, can recurse (up to a maximum call depth of 200) and close over their defining scope.


def fib(n) {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

def is_valid(msg) {
    let first = msg.splitlines()[0]
    return len(first) <= 72 and ': ' in first
}

Functions are the right place for validators — the deterministic code that decides whether to trust an LLM answer. See commit-message.

Built-ins

A compact standard library is available without imports: len, range, sorted, json_parse, log, and Python-style methods on strings, lists and dicts. The full list is on the Built-ins page.
