### Code Completion Tips

- **Member & record field completion**: Type `.` or `?.` after any variable, struct, array, iterator, or `std/*` module (e.g., `human.`, `col.`, `scores.`, `llm.`) to see inferred fields, methods, and extension methods.
- **Import path completion**: Type `import x from "std/` to browse all standard library modules.
- **Named arguments & signature help**: Inside a function call like `feed(human, ` or `@{ ... }.agent(`, press `Ctrl+Space` for named parameter completions and live signature hints.
- **Hover types & JSON Schemas**: Hover any symbol to view its inferred SPL type, or hover `type_schema<T>()` to inspect the compile-time JSON Schema inline.
- **Live OpenAI examples (Vercel deployment)**: Presets `07`–`09` execute `Prompt.ask<T>`, `Prompt.agent<T>`, and `Prompt.llm_fn<In, Out>` live through the server-side `/api/llm/*` route, reading `OPENAI_API_KEY` from Vercel Project Environment Variables (or local gitignored `docs/.env`) without exposing keys to the browser.
