VS Code extension

Language tooling for .md workflows. Markdown remains the document language; frontmatter extension: semantic-prompt-language opts into SPL diagnostics, completion, navigation, and symbols. The server validates version: 1. Ordinary Markdown is left alone; .spl file association is removed. The extension lives in the vscode/ folder of the repository.

Features#

Highlighting#

SPL fences embed the language grammar: keywords, declarations, numbers, comments, and strings with {expr} interpolation. @name references in blockquotes get distinct coloring. Bindings declared in earlier fences support navigation from natural-language markers. Lexical highlighting works independently of frontmatter; runtime execution and language-server features require the opt-in.

Generation & agents#

ask, think, explicit agent, and shared modifiers: len, fmt, reasoning, show, schema, repairs, model. Raw tools use ordinary calls.

Command modifiers use parentheses, including multiline groups such as ask(fmt='integer', repairs=1) 'prompt'. Completions work inside unfinished modifier groups. Logging uses log(level=debug)(value). Document model defaults belong in frontmatter; the model snippet inserts a per-call override.

Runtime inputs#

Read-only $env and $args have highlighting, hover documentation and completions, including inside interpolation. Typing $ triggers completion; accepting $env or $args replaces the whole partial special-variable name without duplicating $. Diagnostics reject unknown special names and attempts to declare/rebind them. The editor never reads the process environment or script arguments. See runtime inputs.

Scopes & failures#

enforce/forbid, restrict [fs|net|exec|mcp] with comma-separated clauses, try/except, assert, fail, success.

Snippets#

Type splworkflow in Markdown for a complete document envelope. Embedded SPL snippets cover control flow, LLM commands, tools and scopes.

Editing#

# comments (Ctrl+/), bracket matching and auto-closing for {} [] () and quotes (including '''), auto-indent after {, #region folding.

Escape checking#

Illegal escapes and stray } in strings are flagged with the invalid scope.

String highlighting understands interpolation {expr}, the {{ }} and \{ \} brace escapes, raw r'…' strings and triple-quoted strings.

Lexical only

The grammar is lexical (TextMate). spl --check rejects unknown/duplicate modifier names; expression values and schemas are validated at runtime. Navigation and completion respect lexical block scopes, including loop and exception bindings. Leveled log modifiers are highlighted and completed separately from generation modifiers.

Install#

For development, open the vscode/ folder in VS Code and press F5 to launch an Extension Development Host.

Snippets#

Type the prefix, then Tab.

LLM ask askobj askschema think agent model

Develop & test#

  • test/*.spl contain scope assertions: a line # ^^^ scope.name asserts the scope of the columns under the carets on the line above (- scope asserts absence). test/run-assertions.mjs runs them with vscode-textmate.

  • test/check-examples.mjs tokenizes every script in ../lang/examples and fails on invalid scopes or on strings/blocks that are left open at the end of a file.

Keep the grammar in sync

When the language changes, update syntaxes/spl.tmLanguage.json together with the canonical Markdown grammar.
