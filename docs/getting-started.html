Introduction

Getting started

From a fresh checkout to a running script in a few minutes. You don't need a Copilot login for the first run — the offline mock backend is enough.

Requirements

  • Node.js 20 or newer.
  • For the default backend: an authenticated GitHub Copilot, for example via gh auth login.
  • Not needed for --backend mock or --check.

Install & build

The interpreter lives in the lang/ folder of the repository.


cd lang
npm install
npm run build

npm install also runs prepare, which compiles the TypeScript sources to dist/. The package exposes two binaries, spl and spl-lang, both pointing at dist/cli.js.

Your first run

  1. Check the syntax. --check parses the script and exits — no LLM, no side effects. 
    
node dist/cli.js examples/basics.spl --check
  2. Run it offline. The mock backend returns deterministic placeholder answers, so control flow and validation can be tested anywhere. 
    
node dist/cli.js examples/basics.spl --backend mock
  3. Run it against Copilot. Without --backend the Copilot SDK is used with your login. 
    
node dist/cli.js examples/live.spl
  4. Or use npx. From a checkout, or as npx spl-lang once published. 
    
npx file:./lang examples/live.spl
ℹ️
stdout vs. stderr

The value passed to success goes to stdout (strings raw, everything else as JSON). Logs — including model, reasoning effort, temperature and seed of every LLM call — go to stderr, so results can be piped safely.

Write a script

Create hello.spl:


# Ask for structured data, validate it, then use it like any other value
let user = ?{fmt='object'} 'Invent a fictional user as {{"name": str, "age": number}}'

assert type(user.age) == 'number' 'age must be a number'

let greeting = ?{len='sentence'} 'Write a greeting for {user.name}, who is {user.age}.'
success greeting


node dist/cli.js hello.spl --backend mock    # offline
node dist/cli.js hello.spl --model gpt-5      # real run with a model override
💡
Literal braces in prompts

Every string interpolates {expr}. To write a literal brace — for example a JSON template — double it ({{ }}), escape it (\{ \}) or use a raw string r'{"a": 1}'.

Exit codes

CodeMeaning
0The script finished (reached success or the end).
1Uncaught failure — the failure payload is printed to stdout.
2Syntax error or command-line usage error.
70Internal interpreter error.
