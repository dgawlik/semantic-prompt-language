Introduction

Getting started

Start with exact raw tools, add schema-validated generation, and opt into agents only when the model should choose actions. Syntax checks, raw tools, and recorded replay need no Copilot login.

Requirements

  • Node.js 20 or newer.
  • An authenticated GitHub Copilot: run spl login once (see Authentication).
  • Not needed for --check or for scripts without LLM commands.

Install & build

The interpreter lives in the lang/ folder of the repository.


cd lang
npm install
npm run build

npm install also runs prepare, which compiles the TypeScript sources to dist/. The package exposes two binaries, spl and spl-lang, both pointing at dist/cli.js.

Your first run

  1. Check the syntax. --check parses the script and exits — no LLM, no side effects. 
    
node dist/cli.js examples/basics.spl --check
  2. Log in to Copilot. Once per machine; it opens GitHub's device flow (a code you confirm in the browser). 
    
node dist/cli.js login
  3. Run it against Copilot. The Copilot SDK is used with your login. 
    
node dist/cli.js examples/live.spl
  4. Or use npx. From a checkout, or as npx spl-lang once published. 
    
npx file:./lang examples/live.spl
ℹ️
stdout vs. stderr

The value passed to success (or to a top-level return) goes to stdout (strings raw, everything else as JSON). Logs — including model and reasoning effort of every LLM call — go to stderr, so results can be piped safely.

Write a script

Create hello.spl:


let User = {
    'type': 'object',
    'properties': {'name': {'type': 'string'}, 'age': {'type': 'integer', 'minimum': 0}},
    'required': ['name', 'age'],
    'additionalProperties': False,
}
let user = ?{schema=User, reasoning='low', repairs=2} 'Invent a fictional adult user'
assert user.age >= 18 'expected an adult'
success user


node dist/cli.js hello.spl --model gpt-5.5    # run with a model override
💡
Literal braces in prompts

Every string interpolates {expr}. To write a literal brace — for example a JSON template — double it ({{ }}), escape it (\{ \}) or use a raw string r'{"a": 1}'.

Exit codes

CodeMeaning
0The script finished (reached success, a top-level return or the end).
1Uncaught failure — the failure payload is printed to stdout.
2Syntax error or command-line usage error.
70Internal interpreter error.

Replay generation offline


node dist/cli.js hello.spl --record hello.jsonl
node dist/cli.js hello.spl --replay hello.jsonl --silent

The second run needs no model credentials. Requests must match exactly and in order. Replay permits local reads but blocks writes, shell, network, agents, and stores. Recordings contain prompts and raw responses; protect them as sensitive data. See record/replay.

Breaking changes in 0.3

OldNew
read_file{path='a.txt'} 'Return it'read_file('a.txt'); interpret the result with a separate generation call.
Tools with missing parametersRequired positional arguments, or explicit agent '...' for model-selected actions.
enforce / forbidinstruct / avoid: prompt guidance only.
think{level='high'}?{reasoning='high'} or think{reasoning='high'}.
let x += 1, let d.key = 2x += 1, d.key = 2; let is for name declarations/redeclarations.
Bare blocks introduce scopesAll blocks share the function/script scope; functions cannot rebind enclosing locals.
Modifier values checked by parsingValues are expressions checked at runtime; unknown/duplicate names remain syntax errors.

Run the tests


cd lang
npm test     # builds and runs the offline suite; no model calls by default

For authenticated live checks, explicitly set SPL_LIVE_TESTS=1. In PowerShell: $env:SPL_LIVE_TESTS='1'; npm test, then remove the environment variable. Documentation snippets and example syntax are checked offline.
