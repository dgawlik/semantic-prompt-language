The mental model

One document.
One shared scope.

SPL brings model-driven steps and deterministic code together. Everything runs top to bottom, so a value created in one step is ready for the next.

    Describe what needs judgment in natural language. Agent tools can load and save values in the workflow's shared scope.

  3. 03

    Use the checked result.

    Validate the returned shape, assert business rules, format Markdown or write a file with ordinary code.

Prompt controls & permissions

Guide the answer.
Limit the effects.

Use ask to get a model response. Wrap it in enforce and forbid to shape the prompt, then use restrict to scope library tool actions.

{js} / guide a response, scope a writeask · restrict
const answer = await enforce(
  'Answer in one sentence',
  () => forbid('jokes',
    () => ask('Explain recursion')));

await restrict('./out', () =>
  writeFile('./out/recursion.txt', answer));

What each wrapper does

  • askReturns a model answer; it has no tools.
  • enforce / forbidAdd prompt guidance. They do not validate the answer.
  • restrictLimits SPL library tools and agents while its callback runs.

Restrictions are not an OS sandbox; direct Node.js APIs are outside their scope.

Keep the distinction visible

Good instructions help.
Checks make rules real.

Model guidance is best effort. Use deterministic checks when a rule must hold, and keep a person in the loop when the result needs review.

01 / Validate

Check the shape.

Types and schemas verify fields and values. Use assertions in JavaScript for exact business rules.

02 / Control

Keep exact work exact.

Use ordinary code and library tools for formatting, file operations and other deterministic effects.

03 / Learn

Trace and review.

Check workflows before running them, record execution history and add human approval where it matters.

Useful boundaries: valid shape does not guarantee correct facts. Prompt instructions are not deterministic checks, replay is not a promise of repeatability, and restrictions on library tools are not an operating-system sandbox.

Your first 30 minutes

Start small.
Then add a model.

Explore types and regular JavaScript before spending a token. When you're ready, configure a provider and run a workflow.

Terminal / from the repository root 
# Install the CLI
npm install -g spl-lang

# Run a no-model example
spl lang/examples/typed-data.md

# Check before running
spl lang/examples/hi.spl --check

# Configure a provider, then run
spl login openai
spl lang/examples/hi.spl --model gpt-4.1
