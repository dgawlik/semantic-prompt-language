Write programs where prompts are syntax.

SPL is a Python-like language with LLM calls built into the grammar. Everything outside the model call is plain, deterministic code — loops, arithmetic, validation, retries — and every tool the model touches is checked by the runtime.

Get started → Read the language guide Browse examples 

@{model='gpt-5.5'}

def fib(n) {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

# an LLM call, validated and parsed as JSON
let joke = ?{len='sentence', fmt='object'} 'A joke about programmers. Give setup and punchline.'

# deliberate before answering
let why = think{level='high'} 'Why is {joke.setup} funny?'

# rules for every call inside the block
let hi = None
enforce 'Answer in English' {
    forbid 'profanity' { let hi = ?'Say hi' }
}

# the model may only touch ./out
restrict './out' {
    write_file{path='./out/a.txt', content='{fib(10)}'} 'Confirm'
}

try { assert fib(5) == 5 'wrong' } except err { log(err.reason) }
success {'joke': joke, 'why': why, 'hi': hi}

Why SPL?

Scripts that glue LLMs to files, shells and the web usually end up as a pile of string-building and ad-hoc parsing. SPL makes the interesting parts first-class and keeps the rest boring on purpose.

🧠

Prompts are expressions

?'…' and think '…' return values you can store, test and pass to functions. Strings interpolate {expr} everywhere.

🧱

Deterministic everywhere else

Control flow, arithmetic, interpolation and variables never touch the model. Only the LLM commands introduce variance.

🔒

Least privilege, enforced

restrict scopes narrow files, hosts and executables. The runtime blocks violations — it doesn't just ask nicely.

✅

Untrusted output, validated

fmt='object' parses JSON for you; assert and try/except turn bad answers into retries.

⚡

Runs with npx

One command-line interpreter, spl login for GitHub Copilot credentials, a pluggable variable store.

🎨

Editor support

A VS Code extension ships highlighting, snippets and bracket handling for .spl files.

Design tenets

🎯
Best-effort reproducibility

Control flow, arithmetic and interpolation are fully deterministic. For LLM calls reproducibility is best effort (the Copilot SDK has no temperature or seed setting). Identical output is not guaranteed — guard with assert and fmt.

🛡️
Least privilege by restriction

The MVP is allow-by-default: a script has the permissions of the user running it. Authors narrow permissions with scoped restrict blocks, enforced by the runtime on every tool call.

How a run works

ParseStrict lexer & parser. Unknown modifiers are syntax errors.
→
InterpretDeterministic evaluation of statements and expressions.
→
AssembleConstraints, restrictions and modifier hints are prepended to the prompt.
→
CallCopilot SDK. Tool calls are intercepted and checked.
→
ResultValue of success to stdout, logs to stderr.

Non-goals

  • Bit-for-bit reproducible LLM output (no record/replay or response cache in the MVP).
  • Being a full Python implementation — only a reasonable subset is supported.
