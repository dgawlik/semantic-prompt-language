The mental model

One file.
Ordinary scope.

SPL interleaves instructions for models and agents with TypeScript. Everything runs top to bottom, and the output of a block is an ordinary variable for the code that follows.

  1. 01

    Set things up in code.

    Read inputs, declare types, import modules and calculate values in TypeScript. Top-level await works, and Node.js erases the types.

  2. 02

    Give the model a task.

    Write what needs judgment between two --- lines. @name reads a variable, and an agent declares what it saves with ->[Type] @name.

  3. 03

    Use the checked result.

    Outputs are coerced to their type and declared in the enclosing scope. Assert business rules, format Markdown or write a file with ordinary code.

Prompt controls & permissions

Guide the answer.
Limit the effects.

Use ask to get a model response. Wrap it in enforce and forbid to shape the prompt, then use restrict to scope library tool actions. In a block, the same three are header keys.

TypeScript / guide a response, scope a writeask · restrict
const answer = await enforce(
  'Answer in one sentence',
  () => forbid('jokes',
    () => ask('Explain recursion')));

await restrict('./out', () =>
  writeFile('./out/recursion.txt', answer));

What each wrapper does

  • askReturns a model answer; it has no tools.
  • enforce / forbidAdd prompt guidance, in code or in a block header. They do not validate the answer.
  • restrictLimits SPL library tools and agents: inside its callback, or for one agent block.

Restrictions are not an OS sandbox; direct Node.js APIs are outside their scope.

Blocks are statements

Branch on data.
Repeat until done.

A block may stand wherever a statement may: at the top level, in a function, inside if, a loop or try. Plain TypeScript decides what runs and how often.

if (topic === 'color') {
    ---

    What is your favorite color? Answer with one word.
    ---

while (i < 2) {
    ---
    mode: agent

    Increment the number @i by one ->[Int] @=i
    ---
}

success({ result, i });
01 / Choose

if · else

An ordinary condition decides whether a block runs. It can read anything earlier code or blocks produced.

02 / Repeat

while · for

A block in a loop runs once per pass. Each pass is a new model call.

03 / Update

=name

An output declares a new constant. Written as =name, it assigns an existing let instead.

04 / Scope

Normal block scoping.

Outputs live in the scope that encloses the block. result is declared before the if, so it stays visible after it.

Keep the distinction visible

Good instructions help.
Checks make rules real.

Model guidance is best effort. Use deterministic checks when a rule must hold, and keep a person in the loop when the result needs review.

01 / Validate

Check the shape.

Output types coerce and verify fields and values, and spl check type-checks the file. Use assertions for exact business rules.

02 / Control

Keep exact work exact.

Use ordinary code and library tools for formatting, file operations and other deterministic effects.

03 / Learn

Trace and review.

Check workflows before running them, record a run with --trace to resume or replay it, and add human approval where it matters.

Useful boundaries: valid shape does not guarantee correct facts. Prompt instructions are not deterministic checks, replay is not a promise of repeatability, and restrictions on library tools are not an operating-system sandbox.

Your first 30 minutes

Start small.
Then add a model.

Explore types and regular TypeScript before spending a token. When you're ready, configure a provider and run a workflow.

Terminal / from the repository root 
# Install the CLI
npm install -g spl-lang

# Run a no-model example
spl run lang/examples/typed-data.spl

# Type-check before running
spl check lang/examples/random-article.spl

# Configure a provider, then run
spl login openai
spl run lang/examples/random-article.spl
