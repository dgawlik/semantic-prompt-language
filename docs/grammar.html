Grammar

The complete syntax of SPL documents and the code inside spl fences, in EBNF. Modifier names are checked while parsing; modifier values and schemas are checked at runtime.

On this page
  • Notation
  • Complete grammar
  • Maintaining the grammar

Notation#

{ x } repeats, [ x ] is optional, | separates alternatives. Statements end at a newline, ;, a closing } or the end of input. Newlines inside () and [] are ignored, and a trailing \ continues a line. Opening braces must be on the same line as their keyword. # starts a comment.

Complete grammar#

Maintaining the grammar#

This page is the only copy of the grammar. When the syntax changes, update it together with the VS Code TextMate grammar, then run npm run docs:build from the repository root. The documentation tests check that the rendered grammar and the example listings stay in sync.
