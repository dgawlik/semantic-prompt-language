Grammar (EBNF)

SPL 0.3 syntax, synchronized from lang/docs/syntax.ebnf. Modifier names are checked while parsing; expression values and schemas are checked at runtime.

On this page
  • Notation
  • Complete grammar
  • Syntax versus semantics

Notation#

{ x } means repetition, [ x ] means optional, and | separates alternatives. Statements end at a newline, semicolon, closing block, or end of input. Opening block braces must share the keyword's line. Comments begin with #.

Complete grammar#

Syntax versus semantics#

let declares in the current block scope; reads and assignment search enclosing lexical scopes. Blocks and conditionals yield their final expression or None. Raw tools are ordinary function calls. Generation and agents share expression-valued modifiers; log has its own level modifier. See language basics and generation contracts for runtime rules.

After changing the grammar or executable examples, update their Markdown copies in docs-template/. Run npm run docs:build from the repository root to regenerate all HTML pages and the search index. Documentation tests check that the embedded grammar and examples remain synchronized.
