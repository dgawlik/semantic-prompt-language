02 / Why it exists

A good prompt is a start.
A workflow needs more.

SPL closes the gap between a convincing answer and a usable result.

01

Too much copy, paste, repeat

Context and steps live across chats and scripts.

One Markdown file, shared variables, ordered execution.

02

Valid-looking, wrong-shaped output

An answer is not automatically application-ready data.

Typed schemas, strict formats and business-rule assertions.

03

Agents with unclear boundaries

A request to “be careful” is not a permission check.

Visible runtime restrictions on files, hosts and tools.

04

Expensive, hard-to-reproduce reruns

Running again can change answers or repeat an action.

Append-only traces and pinned, offline replay.

04 / Exact code

Keep the predictable parts
predictable.

Control flow and exact tools do not call a model. Spend model calls on the ambiguous parts.

Ordinary SPL / no model needed
type Money = int

def line_total(price: Money, qty: int) -> Money:
    return price * qty

let total: Money = 0
for qty in [1, 2, 3]:
    total += line_total(1250, int(qty))

let receipt = object:
    'total_cents': total
success receipt

Familiar control flow

if, loops, functions, lambdas and lexical scopes.

Useful data primitives

Strings, lists, slices, dictionaries and JSON utilities.

Real I/O

read_file, write_file, web_fetch, web_search, shell.

Reusable modules

Import local .spl helpers; build reports with the markdown standard library.

Script inputs

Read CLI arguments through $args and environment values through $env.

Clear outcomes

success returns a result; fail stops explicitly. Logs stay on stderr.

SPL is Python-like, not Python. Blocks use a colon and exactly four spaces per level. Dictionaries use object:, or object() when empty.

Exact means no model involved / external state can still change04 / 12

05 / Built-in model calls

Three ways to use AI.
Choose the right capability.

01 / GENERATE

ask

Returns a value / no tools

Extract, classify, translate or draft when the inputs are already available.

let title = ask(len='sentence') \
    'Title for: {draft}'
02 / REASON

think

Returns a value / no tools

Plan or analyze with medium reasoning by default; raise or lower the effort.

let plan = think(reasoning='high') \
    'Plan migration of {service}'
03 / ACT

agent

Uses runtime + MCP tools

Inspect files, use external tools and take actions within active restrictions.

let report = agent \
    'Inspect tests and report'

Choose your backend. OpenAI, Anthropic or Google through official clients. Select a model per document or call; CLI --model overrides both.

Control the request. Length hints, reasoning, token limits; ask also supports seed, temperature and top_p where supported.

Sampling is best-effort, not reproducibility. Every call starts a fresh conversation: pass the context it needs.

Generate values / reason about inputs / act with tools05 / 12

06 / Optional typed contracts

Make “looks right”
checkable.

Describe the data you expectPrimitives, enums, exact structs, list[T], unions, transparent aliases and callable signatures.

Keep the contract after creationKnown typed errors stop execution before model calls. Runtime boundaries and mutations remain checked.

Separate data from instancesStructs describe records. Classes add identity and methods; direct schema hydration requires hydratable class.

Use exact arithmetic for moneySigned 64-bit int is distinct from finite float. Use cents and explicit numeric conversions.

Shape + meaning / two different checks
type Money = int

struct Invoice:
    vendor: str
    subtotal: Money
    tax: Money
    total: Money

let invoice: Invoice = ask(
    schema=Invoice, repairs=2
) 'Extract invoice amounts in cents: {document}'

assert invoice.subtotal + invoice.tax == invoice.total \
    'totals do not add up'

schema=Invoice selects typed decoding; an annotation alone does not. Struct fields are required and exact, including nullable fields.

Field metadata is model advice, not a business rule. Use assertions for meaning; valid structure does not prove factual correctness. object(instance) creates a deep data snapshot.

Start dynamic / add enforced contracts where they matter06 / 12

07 / Checks & failures

Reject bad output.
Don’t repeat bad actions.

01 / Parse

fmt checks text, numeric, Boolean, array, object or JSON output.

02 / Validate

schema accepts SPL type descriptors or raw JSON Schema.

03 / Repair

repairs=0..5 permits extra attempts on format or schema errors.

04 / Assert

Exact code checks business rules after generation completes.

A strict format is not a range check
let score = ask(
    fmt='integer', repairs=2, tokens=2048
) 'Rate this issue from 1 to 5: {issue}'
assert 1 <= score and score <= 5 \
    'score out of range'
success score

Failures are explicittry / except can handle runtime failures with a reason, source line and status code.

No hidden cleanup magicAssertions are not automatic repair prompts. Tool failures and transport errors are not repaired; agents do not auto-repeat failed actions.

Failures do not roll back earlier writes. Design side effects deliberately.

Validation is deterministic / generation is probabilistic07 / 12

08 / Tools & permissions

Let agents act.
Draw the boundary.

Built-in tools handle files, web access and shell commands. MCP connects agents to your tool ecosystem.

Runtime permissions / narrower scopes intersect
let report = ''
restrict './src', exec 'git', \
    net 'docs.example.com', mcp 'docs/search':
    report = agent \
        'Review source and git diff using docs'
success report

Load MCP with --mcp mcp.json: VS Code-style configuration for stdio, HTTP or SSE servers, with tool allowlists.

fs

Limit files

Resolved paths, including traversal and symlinks, must stay inside permitted roots.

net

Limit hosts

Network calls and redirect hops are checked against allowed hosts.

exec

Limit commands

Allow executable names; check chains, path-like arguments and redirections.

mcp

Limit integrations

Expose only permitted servers or individual tools to agents.

Know the boundary: tools are allowed by default outside restrictions. Restrictions are not an OS sandbox; allowed programs and MCP servers remain trusted. enforce / forbid are prompt guidance, not permissions.

Visible permissions / runtime enforcement / explicit trust08 / 12

09 / Human control & reusable intelligence

Keep people in the loop.
Reuse what works.

Human input

Ask before moving forward

Use human in code, or ask a blockquote agent to consult a person through ask_human.

let approval = human 'Publish? yes/no'
assert approval == 'yes' 'not approved'
success approval

Answer in the terminal, or provide repeated --human flags in question order. Input is a string; validate it explicitly.

Blockquote controls

@CTL(...) sets scoped restrictions, enforce, forbid, model and reasoning before the agent starts.

Explicit code generation

Generate a function, not an action

@CODEGEN produces reusable SPL function definitions for later code and agent steps.

> @CODEGEN 'Define double(value), returning value multiplied by two'

```spl
success double(21)
```

Generated definitions must parse and pass static contract checks. They are not invoked during generation.

Traced runs cache matching definitions in sibling .spl files. Review generated code before trusting it; a description hash is not an integrity guarantee.

Human judgment where needed / reusable code where possible09 / 12

10 / Traces & pinned workflows

A run you can inspect.
A result you can replay.

Capture model answers, decisions, tool outcomes and human input instead of asking the world to behave identically twice.

Append-only history

Resume with --trace

spl flow.md --trace run.jsonl
spl flow.md --trace run.jsonl

The same path resumes recorded work or replays a completed result. Use a new trace file for a fresh run.

Self-contained recorded run

Freeze with --pin

spl flow.md --pin
spl flow.locked.md

A successful run creates locked Markdown containing its execution journal. Replay needs no model login or MCP calls.

No duplicate external effects

Recorded calls, writes, commands and prompts are not repeated. Replay does not restore changed or missing external files.

Mismatch is a failure, not a live fallback

Source and execution settings must match. Interrupted effects with unknown outcomes require manual recovery.

Keep journals and locked files private: they can contain sensitive inputs and environment values. --pin and --trace cannot be combined.

Deterministic replay / not deterministic live generation10 / 12

Notebook sessions retain variables across explicit cell runs. Editing alone never executes a workflow.

edit > --check > run > inspect > refine

Catch problems as you typeParser and type diagnostics, completions, hover and signature help.

Navigate the workflowDefinitions, references and safe rename across Markdown fences and @name references; symbols, folding and semantic highlighting.

Run in the format that fitsCLI for workflows; VS Code notebooks for cells, streamed responses and visible errors. .spl files support modules and editor scratch work.

Integrate and observeEmbed through parseMarkdown, run and AiBackend; use ExecutionSession for retained state. CLI logs expose model/tool events and debug variable changes.

Editor analysis is offline. Notebook execution requires a trusted workspace. The CLI runs Markdown workflows, not standalone .spl scratch files.
